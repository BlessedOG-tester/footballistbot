# Football List Telegram Bot

Бот для еженедельной записи на футбол в групповом чате Telegram.

## Что умеет
- Игроки пишут `+` — бот записывает их, `-` — убирает.
- `+1`…`+5` — записаться с гостями (число = сколько гостей). Повторный `+N` меняет число гостей. Просто `+` гостей не трогает.
- `-1`…`-5` — убрать часть гостей. `-`, `минус`, `не смогу` — выйти вместе со всеми своими гостями.
- Ведёт основу по хронологии сообщений и **резерв**: когда лимит заполнен, новые попадают в резерв.
- Когда кто-то выходит (или админ повышает лимит), первый из резерва **автоматически поднимается** в основу — бот пишет в группе «ты в игре! Приходи!» с упоминанием и пытается написать в личку.
- После каждого `+`/`-` отвечает свежим списком (и ставит реакцию 👍). Закреплённое сообщение со списком при этом тоже обновляется.
- **Манишки.** После `/finish` бот публикует сообщение «Кто забрал манишки стирать — напиши „я взял“» и ведёт список: кто написал `я взял` / `взял` / `беру` / `забрал манишки` — попадает в список. «Я взял» учитывается только после `/finish`. Список живёт, пока админ не обновит его (`/bibs reset` или кнопка в панели) — например, когда манишки вернули; после обновления «я взял» снова игнорируется до следующего `/finish`.
- После `/finish` дата автоматически переносится на неделю вперёд; при `/open` на прошедшую дату бот сам сдвигает её на ближайший такой же день недели.
- **ИИ-слой (опционально, OpenAI).** Если задан `OPENAI_API_KEY`, бот понимает свободные фразы: «я с другом приду» → `+1`, «сегодня не получится» → `-`, «забрал манишки» → учёт манишек; отвечает на вопросы о игре («во сколько сегодня?», «кто в резерве?», «у кого манишки?») с учётом текущего списка и последних сообщений чата; админам — выполняет команды словами («открой запись на пятницу 20:30», «поставь лимит 16», «заверши игру»). Модель только определяет намерение — исполняет его тот же код, что и команды; на болтовню бот не реагирует. Без ключа всё остальное работает как обычно.
- Через час после конца игры просит фото победителей и закрепляет сообщение (только если запись реально открывалась и в списке есть люди).

## Команды

Всем:
- `/list` — показать список.
- `/bibs` или слово «манишки» — у кого сейчас манишки.
- `/help` — подсказка для игроков. `/admin` — список команд админов.

Админам чата (проверяется через права в группе):
- `/open [ДД/ММ/ГГ] [ЧЧ:ММ-ЧЧ:ММ]` — открыть запись, опционально сразу с датой и временем.
- `/close` — закрыть запись.
- `/newgame ДД/ММ/ГГ ЧЧ:ММ-ЧЧ:ММ ЛИМИТ ПОЛЕ` — новая игра (список очищается).
- `/setdate`, `/settime`, `/setfield`, `/setlimit` — поменять параметры. `/setlimit 0` = без лимита.
- `/add Имя` — добавить игрока вручную (например, без Telegram).
- `/remove @username|Имя|№` — убрать игрока (вместе с его гостями).
- `/finish` — завершить игру: очистить список, перенести дату на +7 дней, открыть учёт манишек.
- `/bibs reset` — обновить список манишек (новый круг). `/bibs remove @username|Имя` — убрать человека из списка.
- `/reset` — очистить список игроков без завершения игры (с подтверждением).
- `/menu` или слово «меню» — inline-панель с теми же действиями.

## Быстрый старт локально
```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env           # Windows: copy .env.example .env
python bot.py
```

Тесты логики: `pip install pytest && python -m pytest -q`.

## Переменные окружения
- `BOT_TOKEN` — токен от `@BotFather` (обязательно).
- `STATE_FILE` — путь к файлу состояния. По умолчанию `state.json` рядом с ботом. **На Railway обязательно указать путь на Volume**, см. ниже.
- `OPENAI_API_KEY` — ключ OpenAI (необязательно). Включает понимание свободных фраз и ответы на вопросы. `OPENAI_MODEL` — модель, по умолчанию `gpt-4o-mini` (на чат из ~20 человек выходит примерно $1–3 в месяц).
- `DEFAULT_FIELD`, `DEFAULT_START`, `DEFAULT_END`, `DEFAULT_LIMIT`, `TZ_OFFSET_HOURS` — значения по умолчанию для новых чатов (по умолчанию «Горизонт-арена», 20:30–22:30, 18 мест, UTC+5).

## BotFather
1. Создайте бота через `@BotFather`.
2. `/setprivacy` → **Disable**, чтобы бот видел `+`, `-` и «я взял» в группе.
3. Добавьте бота в чат и сделайте его админом (нужно для закрепления списка; без прав админа бот всё равно работает, просто не закрепляет).

## Деплой на Railway
1. Создайте проект из этого репозитория. `Procfile` запускает `worker: python bot.py`, версия Python — из `.python-version`.
2. **Добавьте Volume** к сервису (Service → Volumes → Add Volume), mount path, например, `/data`. Без этого `state.json` стирается при каждом деплое и рестарте — вместе со списком.
3. В Variables задайте `BOT_TOKEN=...`, `STATE_FILE=/data/state.json` и, если нужен ИИ, `OPENAI_API_KEY=...`.
4. Deploy. В логах должно быть `Bot is running, state file: /data/state.json`.

Бот работает через long polling — никаких портов и вебхуков не нужно. Запускайте только **один** экземпляр с этим токеном, иначе Telegram будет отдавать обновления то одному, то другому.
